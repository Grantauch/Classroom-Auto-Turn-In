# GoClassroom working-name review — 2026-09-20

“GoClassroom” is used in v0.9.22 as a **preview display name**, not as a cleared final trademark.

An initial web search found meaningful education-market overlap:

- GoStudent uses “GoClassroom” in current tutor/help documentation and markets its virtual classroom as “GoClass.”
- A teaching-resource seller uses “GoClassroom” as a shop name.
- Generic school documents also use “GoClassroom” as shorthand for opening Google Classroom.

These findings do not prove that the name is legally unavailable, but they are enough that the project should not claim exclusivity or complete a public 1.0 rename without a proper trademark, domain, Microsoft Store, and repository-name review.

For upgrade safety, v0.9.22 keeps the Windows app ID, product/install name, user-data directory, browser profile, and scheduled-task names from Classroom Auto Turn-In while the display name is evaluated.
